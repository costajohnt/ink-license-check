# Research scripts (unsupported)

These are one-off research artifacts used to build the original candidate list
of Ink dependents (scraping GitHub's dependents graph, filtering by download
count, etc.). They are **not part of the supported tool**, are not covered by
tests or lint, and contain hardcoded local paths (e.g. `/tmp/...`). Kept for
reference only; run at your own risk and expect to edit paths first.
